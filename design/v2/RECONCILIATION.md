# Argon UI v2: reconciling the design and the architecture

`DESIGN_V2.md` (look and UX) and `ARCHITECTURE_V2.md` (modules and contracts) were written in parallel. A final review found that they disagreed in several places and that some features had no owner. This file records the decision taken for each finding. The code follows this file.

## Precedence

1. **DESIGN_V2 wins** on every visual, motion, metric and UX value: tokens, type roles, sizes, radii, motion tokens, breakpoints, layer order, budgets for what is drawn.
2. **ARCHITECTURE_V2 wins** on module contracts: module names, the lifecycle, the scheduler, the commit path, persistence formats, the facade.
3. **This file wins over both** where it states a decision.

## Decisions

| # | Finding | Decision | Code |
|---|---|---|---|
| R1 | Token names differ (ARCH §5.1 lacked `Frame`, `Sheet`, `Well`, `Text2`, `AccentHi`, ...). | DESIGN §2.1 token list. v1 keys stay readable and writable as aliases: `Background`/`Sidebar` = `Frame`, `Window` = `Sheet`, `Input` = `Well`, `AccentLight` = `AccentHi`, `AccentDark` = `AccentDeep`. One `OnStatus` ink. | `theme/Palettes`, `theme/Theme` |
| R2 | Font roles differ; ARCH used a CDN mono face on frame 0. | DESIGN §2.9 roles. Mono is RobotoMono Regular 400 (engine-local). The loader uses only local faces (Montserrat 700, Roboto 400). Roboto 500 and Montserrat 600 are preloaded off-thread and swapped in. Technical keeps v1's Sarpanch. | `theme/Fonts` |
| R3 | Motion tokens differ. | DESIGN §2.11: `hover` 0.10, `press` 0.06, `state` 0.14, three springs (snappy, gentle, dock), `pop.in` 0.16 with UIScale 0.96, `veil` 0.14, `rise` 0.18/6 px, `ghost` 0.26 spring. | `core/Motion` |
| R4 | Metrics differ (radii, window size, density, scale). | DESIGN §2.7-2.8 and §3.2. Radii 20/14/10. Density `Compact`, `Default`, `Touch`, `Gamepad`. Window default `max(min(gui.X-160,1080), min(720,gui.X-16))` x `max(min(gui.Y-110,700), min(440,gui.Y-16))`. Scale accepted 0.75-1.5 through the API, offered 90-130 % in Appearance; `auto` is 1.0 below a 1,300 px tall GUI and `clamp(height/1080, 1, 1.5)` above it. | `theme/Metrics` |
| R5 | Breakpoints differ. | DESIGN §3.6: Wide (window >= 1080), Standard (760-1080), Rail (< 760 or collapsed), phone landscape, phone portrait (bottom tab bar). Sidebar 232, rail 64. | `shell/Shell` |
| R6 | Layer order differs. | DESIGN §3.1: `Base < Overlay < Toast < Modal < Popover < Tooltip < Boot`. The focus ring has no layer; it is re-parented into the layer that owns focus. Layer frames are sized `1/s` under their UIScale `s`, and every placement uses `layers:toLocal()` (finding R14). | `layers/Layers` |
| R7 | Scope of 2.0 (inbox, pins, quick dock, watermark, spark, tab groups). | All ship in 2.0, as ARCH §1.2 (reconciled) lists. | see ARCH §1.2 |
| R8 | Features without an owner: change tracking and undo, keywords, context menu items, ButtonGroup, SetMaterial, SetAccent, Toast actions, callback-error toast, glow pool. | Owners: `component/Changes` (changed set, counters, Reset, one undo batch), `component/Element` (Keywords, `ContextMenu = false`, `AddMenuItem`, `Pinned`), `controls/ButtonGroup`, `theme/Theme` (`setMaterial`, `setAccent`), `feature/Toast` (actions, Undo pill, error toasts), `core/Glow`. `Router.lookup(key)` gives keybind conflicts. | as listed |
| R9 | Instance and stroke budgets contradict each other. | Gates measured on the `perf_workload` mix (10 tabs x 40, all mounted): instances per control including structure <= 11.2, controls only <= 8.8; UIStroke per control <= 0.6; first dropdown open <= 60 instances, 0 after; toast card <= 16; `CreateWindow` <= 34. | `tests/perf.luau` |
| R10 | The loader still revealed a build + `LoadConfiguration` hub at about 1.0 s. | The 150 ms card timer arms only while real work is pending (a mount job, a restore, or zero tabs). The 250 ms quiet rule and the font wait never show the card on their own. `LoadingMinimum` is 0.25 s, counted through the start of the hand-over; the hand-over is <= 0.3 s. Restores slice at 8 ms. Gates: ready -> interactive <= 0.3 s; 500 controls + restore of 240 flags revealed <= 0.6 s. | `shell/Loader`, `persist/Store` |
| R11 | The font preload was banned by the lint. | `GetTextBoundsAsync` is allowed in `theme/Fonts`, only inside `task.spawn`. The sandbox has a stub. Ready waits for the fonts or 800 ms, whichever comes first. | `theme/Fonts`, `build.luau` |
| R12 | v1 tests contradict DESIGN. | `run.luau` keeps every v1 behaviour test. Assertions that pin a v1 pixel value or colour are updated to the v2 value, each one listed in `tests/README.md`. Kept seams: `Content.JumpRail` (chip strip in every layout), a painted `Root.BackgroundColor3` (`Hover` token), a shade `UIGradient` on `Main`, `Sidebar` `UICorner` + `SquareEdge`, List rows of 44 px with up to 3 inline text actions. | `tests/run.luau` |
| R13 | One shadow asset cannot make centred glows. | Two image roles: `shadow` and `glow`. Until the owner uploads the generated PNGs (`tools/gen_assets.py`), both use v1's public shadow image (`rbxassetid://1316045217`), which is a soft 9-slice blob. Glows are capped at 3 per window. | `theme/Assets`, `core/Glow` |
| R14 | Close key and shortcuts collide with Roblox defaults. | Backspace and pad B close the top layer only while a dismissible layer is open, and are sunk through ContextActionService then (so a tool is not dropped). `/` and Ctrl+1-9 act only while the pointer is over the window or focus mode is on. Focus mode starts on arrow keys, Tab or gamepad input, never on a mouse click. Escape is not bound. | `input/Router`, `input/Focus` |
| R15 | Preference keys missing; prefs lost without ConfigurationSaving. | Prefs adds `Material`, `Accent`, `StateLabels`, `Pins`, `SeenHideHint`, `GamepadToggle`, `MouseUnlock`, `ShowCallbackErrors`, `Watermark`, `UserBinds`, `ColorRecents`, `NotificationPosition`, `PaletteRecent`. Pins are stored per profile. Without `ConfigurationSaving` but with `writefile`, prefs go to `ArgonUI/<GuiName>.meta.json`. | `persist/Prefs` |
| R16 | v1 settings rows and setters without a v2 home. | Settings gets a Window section (rename, logo, overlay hotkeys). `SetSmoothTransitions(false)` = reduced motion. Overlay transparency 0.12-0.8 (v1) maps linearly onto the HUD material range 0-0.18. A built-in settings sheet is always reachable from the account menu and the palette. | `feature/Settings` |
| R17 | Coordinates under the per-layer UIScale. | See R6. | `layers/Layers` |
| R18 | Row mechanics left to the implementer. | Platter = Frame + Rows list + one pooled HoverFill outside the list. The section owns the inset dividers and reassigns them on its visibility recount. The control column is a scale width with a UISizeConstraint; the stack flip is decided once per page-width change. Collapse turns AutomaticSize off, tweens to the header height, then restores it. | `component/RowView`, `container/Section` |
| R19 | ColorSequence cannot be tweened; disabled specified three ways. | Switch = Track (state colour) + an `On` child (white + gradient) whose transparency is tweened. Thresholds snap. Disabled and locked are token re-renders, never subtree transparency. | `controls/Toggle`, `component/Element` |
| R20 | The mockup draws effects Roblox cannot. | The docs preview keeps the mockup but drops subtree opacity in pop-ins, uses a uniform radius and labels the remaining CSS-only effects. | `docs/` |
| R21 | Clipboard reads. | Paste reads Argon's internal clipboard, plus `getclipboard` when present. The key gate has no Paste button. Without `setclipboard`, copy actions open a read-only text sheet. | `core/Env`, `feature/Toast` |
| R22 | Live theme preview underspecified. | Window-local repaint inside `Theme.withPalette`; no `Theme.changed`, no Prefs write; 80 ms hover delay, one repaint per frame; only a click calls `Theme.set`. | `feature/ThemePicker` |
| R23 | Clicks pass through the window. | `Active = true` on Main, floating panels, sheets, the dock pill and the orb. | all shell and layer roots |
| R24 | Library branding in host UI. | User-facing text names the window, not the library. Tips depend on the input type. The default logo is the first letter of the window name on an accent plate. | `shell/*` |
| R25 | Idle timers. | Exemptions: the autosave debounce while dirty, visible toasts and the Undo pill, and the watermark refresh while it is enabled and visible. Nothing else runs at idle. | `tests/perf.luau` |
| R26 | Profile metadata. | Meta stores `{count, savedAt}` per profile; `Profiles.duplicate` exists. | `persist/Profiles` |
